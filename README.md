Udacity *Finding Donors for CharityML* project: supervised learning on census data to predict income >$50K.

Setup with [uv](https://docs.astral.sh/uv/): `uv venv && source venv/bin/activate && uv pip install -r requirements.txt`

Then start JupyterLab with: `jupyter lab`
